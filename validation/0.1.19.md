# 朋友的酒 0.1.19 验证记录

记录日期：2026-11-07。基线为本仓库 Java 0.1.18，对照用户提供的 `friendswine-netease-1.0.0.zip`。构建与验收在本地完成；源码与安装包入口见 [README](../README.md)，不能把远程上传视为新增实机验证。

## 改动

- 玩偶工作台配方为 `SWS / WRW / 空W空`，S 为线、W 为任意颜色羊毛、R 为红石；不同颜色可以混用。
- 遥控器由一个铁块和一个红石块无序合成，允许使用玩家背包的二乘二合成栏。
- 酒由八个小麦围住一个普通水瓶合成。沿用原版有序配方的配方书、结果及网络编码，增加水瓶内容校验；粗制药水、其他药水、喷溅药水和空瓶不能替代。
- 聚集与绕圈共用的站位半径扩大到十格，六角网格按实际行距扩大。优先填充安全内圈，同半径优先选路程短的点，已有有效站位继续复用。
- 按碰撞箱外接圆为玩偶、生物和到站误差保留间距，避免绕圈转角改变后相互挤压。地面、方块碰撞、原版寻路及空间不足时的接近策略继续沿用。
- 六个目标均同步。1.20.1、1.21.1、26.1.2 使用各自的配方目录、材料和结果格式；移植工程构建时排除共用目录中不属于本版本的配方资源。

本轮未修改默认圈速、音乐设置、角色大小设置及《烧心琵琶曲》代码。站位使用十格半径，不代表每个生物都站在十格边缘；内圈有安全空间时仍优先靠近玩偶。旧存档无需迁移，旧配置继续生效。

## 验证项目

服务端真实配方管理器检查混色羊毛、二乘二无序合成、普通水瓶、四类错误瓶子及小麦缺失。站位测试分别检查十二只生物的实际移动、连续停稳、间距、稳定性，以及内圈被方块封住时使用五至十格外圈并遵循方块碰撞。原有绕圈测试检查圈速、暂停、卸载、重载、停止和拆除。

基础站位场景确认外侧生物实际移动后连续停稳五刻，防止把初始零速度或转向瞬间误判为到站；圈速场景在生物实际靠近后开始计圈。十格外圈另由独立的障碍场景验证。

Forge 1.20.1 的旧夹具在模板边界外也铺设地面和生成生物；前场残留生物及死亡动画会推挤后场生物，造成范围外移动、停稳或卸载断言失败。本轮夹具在实际使用的六十四格区域内直接移除旧生物，并停止前场活动玩偶；仅作用于 GameTest，未修改模组卸载或玩家存档行为。最终在全新隔离世界中复测通过，原运行目录及失败现场未删除。

隔离入口为 validation/isolated-gametest.gradle；从仓库根目录运行时，用绝对路径传入 --init-script 并追加 --no-configuration-cache，确保每次创建新测试目录。例如：

```powershell
$testInit = (Resolve-Path ./validation/isolated-gametest.gradle).Path
./ports/forge-1.20.1/gradlew.bat -p ./ports/forge-1.20.1 build runGameTestServer --init-script $testInit --no-configuration-cache
```

本机测试复用已有缓存；Fabric 1.20.1 以 JDK 21 启动 Gradle、JDK 17 运行测试，显式提供已安装的 JDK 路径。
