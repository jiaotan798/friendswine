# 朋友的酒 0.2.1 验证记录

0.2.1 修复生物旋转、缩放时拴绳整体被带转的问题。持绳端按牵引者自身动画计算，再换算到被拴生物的动画局部空间；原版继续绘制挂点、绳段和悬垂。实体外层动画保留，YSM 玩家模型仍可跟随音乐运动。

## 构建与成品核对

2026-11-12，独立仓库的六个 Java 工程使用各自 Wrapper 完成离线 `assemble`。Forge 1.20.1 使用 JDK 17；Fabric 1.20.1 使用 JDK 21 构建、输出 Java 17 字节码；1.21.1 使用 JDK 21，26.1.2 使用 JDK 25。依赖缓存复用，未做无缓存首次联网构建。

客户端验收使用本次修复的未发布 0.2.0 包；升版后六个 0.2.1 JAR 逐项解包比较，仅加载器元数据中的版本号变化，全部类文件和其他资源逐字节一致。验收包与发布包的 SHA256、变化条目及 23 个场景结果见 [结果清单](0.2.1-results.json)。正式成品未包含验收探针。共用逆变换函数的 [60 组旋转与缩放断言](LeashAnimationCheck.java) 再次通过，覆盖最大横向缩放、纵向压缩、挂点和重复计算。

## 双客户端联机、光影与 YSM

每轮使用独立专服和两个实际客户端，依次检查待机、玩偶播放旋转、播放中资源重载、停止恢复。两端收到两名玩家、玩偶和相互牵引的羊驼后，才进行真实拴绳渲染采样及截图。光影启用状态由实际 Iris／Oculus API 确认；播放和重载后的双端画面另经人工查看。

光影为 Complementary Unbound r5.8.1，以及本机的 BSL v10.1.3＋Clrwl 1.0.5 组合包。Forge 使用 Oculus 1.8.0＋Embeddium 0.3.31，其余端使用对应 Iris＋Sodium。YSM 使用默认模型，NeoForge 26.1.2 使用官方 2.6.5 hotfix。按[官方支持列表](https://yesstevemodel.github.io/en/wiki/intro/)，YSM 2.6.5 支持上述五种组合，没有 Fabric 26.1.2，故该端没有 YSM 实测结论。

23 个场景通过，保存 184 张阶段截图；每轮专服与两客户端均以退出码 0 结束。生产补偿函数返回的端点经外层动画还原后，最大误差为 **7.5394575 × 10⁻⁷ 格**，低于 0.0001 格阈值；无动画时端点保持原值。所有客户端在后台隐藏、无焦点、无鼠标捕获和静音状态运行。

## 验证边界

早期尝试中有测试入口初始化失败和个别登录超时，修正入口并完整重跑后通过；这些尝试未计入 23 个 PASS，失败日志保留。Forge 无光影 YSM 场景部分羊驼视角被村庄遮挡，端点采样通过，两种光影场景另有无遮挡截图。

本轮覆盖 Windows 本机专服双客户端、上述光影和默认 YSM 模型。公网延迟、多玩家压力、全部自定义模型及其他光影版本未验证；服务端 GameTest 和《烧心琵琶曲》兼容组合未重跑。历史玩法测试见 [0.1.19 验证记录](0.1.19.md)，附属组合的既有覆盖见 [0.2.0 验证记录](0.2.0.md)。
